# FAQ

### Q: Do I need a personal AWS account?
A: A: No, it's not necessary. Please refer to [AWS Setup](00_preparation.md#aws-setup). Development will be done using the organization's AWS account, so developers should request account creation if needed.

### Q: Is it okay to run terraform apply?
A: Yes, you can run it as needed for assigned issues.

### Q: What is the difference between "QuantumCloudPlatform" and "oqtopus-cloud"?
A: Please refer to [Repository List](00_preparation.md#repository-list).

QuantumCloudPlatform: For creating issues. Access requires permission, so developers should request access if necessary.

oqtopus-cloud: For development. Use this repository for issue fixes or document updates.
